# odaagame.com

The website for One Dungeon After Another. Plain HTML and CSS, no build step, no outside requests, no cookies.

- `index.html`, `style.css`: the page.
- `fonts/`: the game's own fonts, self-hosted, with their SIL Open Font License texts.
- `img/`: the title painting and the logo mark, from the game (`assets/ui/menu/`).

Every change is previewed before it goes live. Every page is checked against the studio's rule that
nothing public names another game (grimhollow-docs `LEGAL.md` 2.3).
